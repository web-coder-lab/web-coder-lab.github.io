NEXGUARD 1.0.3

20 October 2026

What's new

  • Settings footer shows NEXGUARD and the real version number.
  • The English interface uses monitoring wording instead of protection wording.
  • 25 language options. All text is translated, but the translations are machine-generated and not yet reviewed by native speakers.
  • New installs monitor user-installed apps by default; system apps start excluded. Existing choices are not overwritten.
  • Backup and device-transfer rules exclude the notification database and preferences.
  • An About section shows the version, source link and license.
  • The unused FOREGROUND_SERVICE permission was removed. The app does not start a foreground service.

Install

  1. Download the APK.
  2. Open it. If Android asks, allow installs from your browser or file manager.
  3. Open NEXGUARD, grant notification access and choose your apps.

You can install it over 1.0.1 or 1.0.2, because they were signed with the same key. If Android reports a signature mismatch, uninstall the old copy first.
