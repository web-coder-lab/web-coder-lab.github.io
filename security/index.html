Security and data practices

NEXGUARD has not had an independent security audit and holds no certifications. This page describes the permissions of a released APK, read from the manifest of the released APK, version 1.0.3, and checked again for every release.

Permissions

POST_NOTIFICATIONSShows the app's own diagnostic notices on Android 13 and later.
RECEIVE_BOOT_COMPLETEDReschedules diagnostics after the phone restarts.
REQUEST_IGNORE_BATTERY_OPTIMIZATIONSOpens the system screen where you can exempt NEXGUARD from battery limits.
ACCESS_NETWORK_STATEReads whether a network is available for the diagnostics screen. It is not used to upload data.
VIBRATESupports local alert feedback.
QUERY_ALL_PACKAGESLists installed apps so you can choose which ones to monitor. This is broad app visibility.
WAKE_LOCKUsed by the background-work library.
Notification access (system setting)Required by Android so the app can observe posted and removed notifications.

Network

The app does not request the internet permission.

Backup

Android backup is switched off. The notification database and preferences are also excluded from cloud backup and device transfer.

Foreground service

The app does not start a foreground service. The unused permission was removed in 1.0.3.

Signing

Releases are built by GitHub Actions and signed with one key. Certificate SHA-256:
